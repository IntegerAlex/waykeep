# Security policy

## Reporting a vulnerability

Please do not open a public issue for a security problem.

- Preferred: [private vulnerability report](https://github.com/IntegerAlex/waykeep/security/advisories/new)
- Email: inquiry.akshatkotpalliwar@gmail.com

Include the app version, the steps to reproduce, and what an attacker gains. A capture, a
logcat excerpt, or a small proof-of-concept file helps.

## What to expect

- Acknowledgement within 7 days.
- An assessment within 14 days: whether it is a vulnerability, which versions are affected,
  and the plan.
- Credit in the release notes unless you would rather stay anonymous.

Waykeep has no server component, so there is no hosted service to coordinate a disclosure
window with. Please give us time to ship a release before publishing details.

## Supported versions

The latest release and the current `main` branch receive fixes. Older releases do not.
